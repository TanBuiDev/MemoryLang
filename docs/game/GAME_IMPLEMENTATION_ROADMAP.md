# Game Implementation Roadmap

## Phase 0 — Foundation

- Chốt product principles.
- Chốt mission script MVP.
- Kiểm tra deck ordering.
- Kiểm tra data quality.
- Xác định progress persistence.

## Phase 1 — Mission Engine MVP

- Mission types.
- Deck → mission splitter.
- Mission runtime.
- Matching stage.
- Listening stage.
- Context stage.
- Recall stage.
- Boss stage.
- Result stage.

## Phase 2 — Integration

- Game Hub entry.
- Deck selector.
- Mission map.
- Audio integration.
- study_sessions integration.
- user_terms/SRS integration.
- Restore interrupted session.

## Phase 3 — Progress

- Mission completion.
- Deck progress.
- Locked/unlocked missions.
- Continue learning CTA.
- Statistics.

## Phase 4 — Content Pipeline

- Auto question generation.
- Content validation.
- Admin review tooling.
- Special-case manual content.

## Phase 5 — QA

- Unit tests.
- Integration tests.
- Mobile testing.
- Audio fallback tests.
- RLS/security checks.
- Data integrity checks.

## Phase 6 — Expansion

- Additional mission scripts.
- Review Battle.
- Boss Rush.
- Listening Focus.
- Achievements/XP persistence if needed.

## MVP exit criteria

MVP chỉ hoàn thành khi một deck mới có thể được đưa vào hệ thống và chơi được mà không cần sửa code game.
